# Daily Task Manager

A simple console-based task management application developed using Python 3.

## Project Information

- **Project Title:** Daily Task Manager
- **PS Number:** 28
- **Language:** Python 3
- **Project Level:** First Year B.Tech CSE (AI & ML)

## Project Description

Daily Task Manager is a Python-based console application that helps users manage their daily tasks. Users can add tasks, assign priorities, set due dates, view pending tasks and mark tasks as completed.

The application uses basic Python programming concepts and normal text file handling to store task information.

## Features

- Add new tasks
- Assign High, Medium or Low priority
- Set task due dates
- Automatically generate unique task IDs
- View tasks according to priority
- Display pending tasks
- Mark tasks as completed
- Save tasks permanently in a text file

## Technologies Used

- Python 3
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- File Handling
- Date Validation

## How to Run

1. Install Python 3.
2. Open this project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python daily_task_manager.py
```

## File Storage

All task records are stored in a normal text file named `tasks.txt`.

- `daily_task_manager.py` – Main Python source code
- `tasks.txt` – Stores task records
